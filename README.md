# mpv-bb5

找了不少 Windows 的懒人包 mpv，都不太符合我的要求，最后还是决定自己写配置

![](docs/1.jpg)

## 使用方法

下载仓库并放入 `mpv.exe` 所在文件夹的 `portable_config` 文件夹

```
📁 mpv/
├── 📦 mpv.exe
├── 📦 yt-dlp.exe
└── 📁 portable_config/
    ├── 📁 fonts
    ├── 📁 script-opts
    ├── 📁 scripts
    ├── 📄 input.conf
    └── 📄 mpv.conf
```

## 使用的三方库

- [Samillion/ModernZ](https://github.com/Samillion/ModernZ) 本项目 UI 基于 ModernZ
- [po5/thumbfast](https://github.com/po5/thumbfast/) 本项目使用 thumbfast 实现进度条预览
